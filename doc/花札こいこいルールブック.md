## 札の構成

花札は全48枚で、12ヶ月それぞれに4枚ずつの札があります。

### 月別札一覧

| 月 | 光札(20点) | 種札(10点) | 短札(5点) | カス札(1点) |
|----|-----------|-----------|----------|------------|
| 1月 (松) | 鶴 | - | 赤短 | 2枚 |
| 2月 (梅) | - | 鶯 | 赤短 | 2枚 |
| 3月 (桜) | 幕 | - | 赤短 | 2枚 |
| 4月 (藤) | - | 不如帰 | 短冊 | 2枚 |
| 5月 (菖蒲) | - | 八橋 | 短冊 | 2枚 |
| 6月 (牡丹) | - | 蝶 | 青短 | 2枚 |
| 7月 (萩) | - | 猪 | 短冊 | 2枚 |
| 8月 (芒) | 月 | 雁 | - | 2枚 |
| 9月 (菊) | - | 盃 ※ | 青短 | 2枚 |
| 10月 (紅葉) | - | 鹿 | 青短 | 2枚 |
| 11月 (柳) | 小野道風(雨) | 燕 | 短冊 | 1枚 |
| 12月 (桐) | 鳳凰 | - | - | 3枚 |

### 札の種類と枚数

- **光札 (Hikari)**: 20点札、全5枚
- **種札 (Tane)**: 10点札、全9枚
- **短札 (Tan)**: 5点札、全10枚
- **カス札 (Kasu)**: 1点札、全24枚

> **注意**: 札の基本点数は役の判定にのみ使用され、ゲームの得点には直接影響しません。

※ **菊に盃(9月種札)の特殊ルール**: この札は種札としてカウントされると同時に、カス札としてもカウントされます。つまり、カス札9枚+菊に盃でカス役（10枚）が成立します。

## ゲームの準備

### 1. 対戦形式
- 1対1の二人対戦
- 両プレイヤーは対等な操作を行う（先手・後手の区別あり）

### 2. ゲーム設定
- ゲーム開始時に対戦月数を選択
  - **6か月戦**: 6ラウンド
  - **12か月戦**: 12ラウンド

### 3. 各ラウンドの準備

1. **札の初期化**
   - 48枚の札をシャッフル

2. **配札**
   - プレイヤーの手札: 8枚
   - CPUの手札: 8枚
   - 場札: 8枚
   - 山札: 残り24枚

3. **配札後のチェック**
   - 手四の確認
   - くっつきの確認
   - 場札の4枚揃いチェック（後述）

## ゲームの進行

### ターンの流れ

ゲームはプレイヤーとCPUが交互にターンを行います。

#### プレイヤーのターン

1. **手札を1枚選んで場に出す**
   - 場に同じ月の札がある場合: その札を取る（複数ある場合は選択）
   - 場に同じ月の札がない場合: 場に札を置く

2. **山札から1枚引く**
   - 場に同じ月の札がある場合: 自動的にその札を取る
   - 場に同じ月の札がない場合: 場に札を置く

3. **役の確認**
   - 役が成立している場合: こいこい判断へ
   - 役がない場合: CPUのターンへ

#### 相手プレイヤーのターン

相手プレイヤーも同様の手順でターンを実行します。
- 手札から1枚選んで場に出す
- 山札から1枚引く
- 役が成立した場合、こいこい判断を行う（実装によっては自動判定）

## 札の取り方

### 基本ルール

1. **1対1のマッチング**
   - 手札または山札から出した札と、場にある同じ月の札1枚を取る
   - 両方とも自分の取札に加える

2. **マッチしない場合**
   - 出した札は場に残る

3. **場に同じ月が複数枚ある場合**
   - プレイヤーはどれを取るか選択できる（手札から出す場合のみ）
   - 山札から引いた場合は、同じ月の札を1枚ずつ順次取得

### 特殊ケース：場に同じ月が3枚ある場合

> **重要ルール**

場に同じ月の札が3枚ある状態で、その月の4枚目の札を出した場合：
- **場の3枚 + 出した1枚 = 計4枚すべてを取札とする**

**例:**
```
場: [1月カス][1月カス][1月短冊]
手札から[1月鶴]を出す
→ 4枚すべてを取札に追加
```

### マッチング処理の優先順位

1. 手札から場への出札
2. 場の札との照合・取得
3. 山札からドロー
4. ドローした札と場の札との照合・取得

## 役一覧

### 光札系

| 役名 | 条件 | 得点 |
|-----|------|------|
| **五光** | 光札5枚すべて | 10点 |
| **四光** | 光札4枚（雨を含まない） | 8点 |
| **雨四光** | 光札4枚（雨を含む） | 7点 |
| **三光** | 光札3枚（雨を含まない） | 5点 |

> **補足**: 雨 = 11月の小野道風（柳に小野道風）

### 種札系

| 役名 | 条件 | 得点 |
|-----|------|------|
| **猪鹿蝶** | 萩に猪(7月) + 紅葉に鹿(10月) + 牡丹に蝶(6月) | 5点 |
| **タネ** | 種札5枚以上 | 1点 + 超過分×1点 |

**タネの得点例:**
- 5枚: 1点
- 6枚: 2点
- 7枚: 3点
- 以降1枚増えるごとに+1点

### 短札系

| 役名 | 条件 | 得点 |
|-----|------|------|
| **赤短** | 松(1月)・梅(2月)・桜(3月)の短冊3枚 | 5点 |
| **青短** | 牡丹(6月)・菊(9月)・紅葉(10月)の短冊3枚 | 5点 |
| **タン** | 短札5枚以上 | 1点 + 超過分×1点 |

### カス札系

| 役名 | 条件 | 得点 |
|-----|------|------|
| **カス** | カス札10枚以上 | 1点 + 超過分×1点 |

> **注記**: 菊に盃(9月種札)は種札かつカス札の両方としてカウントされます。

**カスの得点例:**
- 10枚: 1点
- 11枚: 2点
- 12枚: 3点

### 特殊役

| 役名 | 条件 | 得点 |
|-----|------|------|
| **月見酒** | 芒に月(8月光) + 菊に盃(9月種) | 5点 |
| **花見酒** | 桜に幕(3月光) + 菊に盃(9月種) | 5点 |

## 特殊ルール

### 1. 手四（てし）

**発生条件:**
- 配札直後、手札に同じ月の札が4枚揃っている

**効果:**
- その時点でただちに勝利
- ラウンドを獲得

**例:**
```
手札: [1月鶴][1月短冊][1月カス][1月カス] + 他4枚
→ 手四成立、即座に勝利
```

### 2. くっつき

**発生条件:**
- 配札直後、手札に同じ月の札が2枚ずつ、4組揃っている

**効果:**
- その時点でただちに勝利
- ラウンドを獲得

**例:**
```
手札: [1月×2枚][3月×2枚][7月×2枚][10月×2枚]
→ くっつき成立、即座に勝利
```

### 3. 場の4枚揃い

**発生条件:**
- 配札直後、場に同じ月の札が4枚揃っている

**効果:**
- 配り直し、またはルールに応じた処理

## 得点計算

### こいこい判断

役が成立した時点で、プレイヤーは以下を選択します：

#### 1. 勝負（ラウンド終了）
- その時点の役の得点を獲得
- ラウンドを終了

#### 2. こいこい（続行）
- ゲームを続行し、さらに役を狙う
- **リスク**: 相手が先に役を成立させた場合、相手の得点が2倍になる

### こいこい時の得点倍率

| 状況 | 得点倍率 |
|------|---------|
| こいこいせずに勝負 | 1倍（通常） |
| こいこい後に自分が勝利 | 1倍（通常） |
| こいこい後に相手が勝利 | 2倍（相手の得点） |

### ラウンド終了条件

以下のいずれかで1ラウンド終了：

1. プレイヤーが役を成立させて「勝負」を選択
2. CPUが役を成立
3. 手札と山札がすべてなくなる（流局）
   - この場合、得点なし

---

## 勝敗の決定

### ラウンド勝敗
- 役を成立させたプレイヤーが、そのラウンドの勝者
- 役の得点を総得点に加算

### ゲーム全体の勝敗
- 設定した月数（6または12ラウンド）終了後
- 総得点が高い方が勝利

## 実装時の考慮事項

### ゲーム状態の管理
#### 札のデータ

各札は以下の情報を持ちます：

```
札:
- 月 (1～12)
- 種類 (光/種/短/カス)
- 基本点数 (20/10/5/1)
- 画像識別子
```

#### プレイヤーのデータ

```
プレイヤー:
- 手札リスト (最大8枚)
- 取札リスト (獲得した札)
- プレイヤー識別子 (先手/後手、またはプレイヤー1/プレイヤー2)
```

> **重要**: 両プレイヤーは基本的に同じ操作を行います。UI実装においてのみ、人間操作とコンピュータ操作の区別が生じます。

#### ゲーム全体のデータ

```
ゲーム:
- 山札 (最大48枚、ゲーム中は減少)
- 場札リスト (最大8枚、増減する)
- プレイヤー情報 ×2
- 現在の月数 (1～設定月数)
- 総月数 (6 or 12)
- プレイヤー1総得点
- プレイヤー2総得点
- 現在の状態
- こいこい宣言フラグ
```

### 処理フロー概要

```
1. ゲーム開始
   ↓
2. 月数選択 (6 or 12)
   ↓
3. ラウンド開始
   ↓
4. 配札 (手札8、場8、山24)
   ↓
5. 特殊役チェック (手四/くっつき)
   ↓
6. ターン処理ループ
   - プレイヤー1（先手）ターン
     - 手札選択
     - 場札選択/配置
     - 山札ドロー
     - 役判定（山札処理後）
       - 役あり → こいこい判断
       - 役なし → プレイヤー2へ
   - プレイヤー2（後手）ターン
     - 同様の処理
   ↓
7. ラウンド終了
   - 得点加算
   ↓
8. 次ラウンドまたはゲーム終了判定
```

### 自動プレイヤー（AI）思考アルゴリズム（参考実装）

> **注**: 両プレイヤーは操作として対等ですが、UI実装でコンピュータ操作を実装する場合の参考です。

基本的なAI思考は以下のロジックで実装可能：

1. **手札選択**
   - 場にマッチする札があればそれを優先
   - なければランダム選択

2. **場札選択（複数マッチ時）**
   - より価値の高い札種を優先（光 > 種 > 短 > カス）
   - 同種ならランダム

3. **こいこい判断**
   - 簡易実装: 常に勝負を選択
   - 高度実装: 得点、残り札数、現在の役などから判断

## 補足情報

### 役の重複

複数の役が同時に成立する場合、**すべての役の得点を合算**します。

**例:**
```
取札:
- 光札3枚（雨なし）→ 三光 5点
- 種札6枚 → タネ 2点
合計: 7点
```

### 役成立の判定タイミング

役の判定は以下のタイミングで行います：

- **各プレイヤーのターン終了時**（山札から引いて取った後）

手札から札を出して取った直後ではなく、山札からのドロー処理を含めたターン全体の処理が完了した時点で役判定を行います。

**処理順序:**
1. 手札から1枚選んで場に出す → 場札と照合・取得
2. 山札から1枚引く → 場札と照合・取得
3. **この時点で役判定** ← 判定タイミング

### シャッフルアルゴリズム

公平性を保つため、**Fisher-Yates シャッフル**などの均等分布を保証するアルゴリズムの使用を推奨します。
